# Sorella Tea POS v2.1.0 — Visual Refresh + Expanded Menu

## Visual changes
- Reworked the order screen toward the approved pastel pink/cream reference layout.
- Product cards use larger square image areas and `object-fit: contain` so cups/items are not cropped.
- Existing product photos were normalized to clean 600x600 presentation canvases with generous whitespace.
- Added newly generated realistic Sorella-branded iced coffee product photography for the expanded Iced Coffee menu.
- Added generated add-on and snack imagery.
- Added `sorella_v210_visual_reference.png` as the approved visual direction reference.
- Bumped image cache version to prevent Netlify/browser cache from retaining older cropped assets.

## Menu organization
- Canonical categories: Milk Tea, Fruit Tea, Fruit Soda, Iced Coffee, Snacks, Add Ons.
- Existing Hot Coffee tab remains disabled as before; old records are not deleted.
- Fruit Tea items stay under Fruit Tea; Fruit Soda stays under Fruit Soda; Fries/snacks stay under Snacks.
- Added more Fruit Tea flavors based on common Philippine milk-tea menu patterns: Blueberry, Green Apple, Grapefruit, Peach Lychee.
- Added Peach and Passion Fruit Soda.
- Added Iced Coffee series filters: Caramel, Mocha, Vanilla, Hazelnut, alongside Signature/Matcha/Taro/Cloudy/Chocolate.
- Added more Iced Coffee products and assigned them to relevant series.
- Added snack choices with Small/Medium/Large and flavor choices.
- Added Nachos with Cheese, Chicken Pop, Potato Wedges, and Chicken Nuggets.
- Added Add Ons: Pearl (Tapioca), Nata de Coco, More Milk, Cheese Foam, Oat Milk, Whipped Cream.

## Copilot
- Existing Copilot message composer remains enabled.
- Added/retained Regroup Categories quick action.
- Price-changing actions still require explicit confirmation before database writes.

## Database safety
- Upgrade is additive: missing bundled products/categories/series are added to an existing database.
- Existing products are not bulk-deleted.
- Existing Hot Coffee records are not deleted; the category remains disabled on the order screen.
