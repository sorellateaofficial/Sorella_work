# Sorella Tea POS v2.6.0 — Expanded Copilot

- Built on the uploaded v2.5.0 POS; existing POS architecture and database are preserved.
- Copilot now supports richer read-only queries for menu, categories, products, recipes, ingredients, inventory, sales and best sellers.
- Added confirmed Copilot actions for:
  - Add an ingredient to inventory
  - Set/change an ingredient's current stock
  - Add a new menu flavor/product to a category or series
  - Change product prices
- All Copilot database writes require explicit Confirm/Cancel.
- Added quick actions for ingredient inventory creation, new flavor creation, best sellers, and inventory value.
- Enter sends Copilot messages; Shift+Enter creates a new line.
