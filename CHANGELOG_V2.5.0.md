# Sorella Tea POS v2.5.0 — Inventory Editor + Expanded Copilot

- Added direct Edit Stock action in Manage → Inventory.
- Added Edit Ingredient action in Manage → Ingredients.
- Manual stock edits are written to the database and logged as Correction movements.
- Ingredient name changes synchronize recipe ingredient names by ingredient ID.
- Expanded Copilot with inventory summary, sales summary, ingredient lookup, recipe lookup, product search, and richer help/quick actions.
- Preserved existing product price confirmation flow.
